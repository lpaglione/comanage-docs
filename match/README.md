# COmanage Match User Guide

This directory is reserved for the COmanage Match User Guide documentation.

When the Match documentation project begins, this directory will contain:
- `conf.py` — Sphinx configuration for the Match RTD project
- `index.rst` — Match User Guide home page
- `requirements.txt` — Sphinx dependencies
- Section subdirectories mirroring the Match User Guide IA

A second Read The Docs project will be created pointing to `match/conf.py`.
