Upgrading to v5
===============

.. sidebar:: On this page

   .. contents::
      :local:
      :depth: 1


This page covers the process for upgrading an existing Registry v4 deployment
to Registry v5, including version-specific notes for each v5 release.

   <https://spaces.at.internet2.edu/display/COmanage/Upgrading+Registry+to+v5.0.0>`_
   and the version-specific upgrade pages in the Technical Manual.
