Match Integration
=================

.. note::

   This page is under development.

COmanage Registry can integrate with **COmanage Match**, a separate service that
detects and resolves duplicate identity records. When a new person record is
created or updated, Registry can query Match to determine whether the person
already exists in the system — preventing duplicates before they are created
and providing a workflow for resolving potential matches when they are found.
